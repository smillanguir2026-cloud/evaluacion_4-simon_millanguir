# Uso de IA — Evaluación 4

## 1. Herramientas utilizadas

ChatGPT mediante Codex. No se registró la versión exacta del modelo.

## 2. Propósito de uso

Se solicitó orientación para estructurar la migración del portafolio a React y TypeScript y comprender la función de sus carpetas y herramientas. También se utilizó asistencia para propuestas de código, correcciones y documentación.

## 3. Prompts representativos

Reformulaciones de las consultas realizadas durante el desarrollo:

- «¿Cómo organizo el proyecto para migrarlo a React?»
- «¿Para qué sirve Context y cuándo lo pide la rúbrica?»
- «¿Qué relación hay entre JavaScript y TypeScript?»
- «¿Cómo organizo las imágenes en assets?»

## 4. Output recibido

Se recibió una organización por componentes, páginas, datos, tipos, hooks y contexto. Las explicaciones abordaron TypeScript, navegación SPA, estado local y Context API.

También se recibieron propuestas de implementación del formulario, estilos BEM, consulta a GitHub y tema claro/oscuro, además de apoyo con Git y redacción técnica.

## 5. Ajustes y verificación

Las propuestas se incorporaron y ajustaron en Visual Studio Code con asistencia. Se corrigieron imports, ubicación de tipos y referencias de imágenes, y se adaptaron las tarjetas para destacar la calculadora.

Se realizaron algunas ediciones directas asistidas de archivos. La compilación y ESLint finalizaron sin errores en la última revisión. Las comprobaciones manuales deben registrarse con sus resultados reales en el README.

## 6. Reflexión crítica final

La guía facilitó organizar el trabajo y distinguir las responsabilidades de cada parte de React. Las dudas durante la implementación mostraron que copiar una solución no equivale a comprenderla.

El aprendizaje requiere revisar las propuestas y poder explicar cómo se conectan los componentes, cómo cambia el estado y cómo se consulta la API. Las comprobaciones automáticas ayudan a detectar errores, pero no sustituyen esa comprensión.

Antes de entregar, el autor debe personalizar esta reflexión indicando qué conceptos puede explicar sin asistencia y cuáles necesita reforzar.
